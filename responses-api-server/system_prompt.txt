Run modes
  ./zap zap   input.txt  output.zap   # compress
  ./zap unzap input.zap  output.txt   # decompress

Encoder pipeline
  1. Count frequency of every ASCII character, including whitespace
     and punctuation.  If the file is empty, print
       <file> is empty and cannot be compressed.
  2. Build a Huffman tree using a min‑heap
       priority_queue<HuffmanTreeNode*, …, NodeComparator>.
  3. Generate codes (left = 0, right = 1).  For a single‑character
     file, either 0 or 1 is acceptable.
  4. Convert the input text to one long bitstring.
  5. Serialize the tree in preorder:
       internal node  -> 'I'
       leaf node      -> 'L' followed by the char
  6. Call ZapUtil::writeZapFile(bitstring, serializedTree) and print
       Success! Encoded given text using N bits.

Decoder pipeline
  1. ZapUtil::readZapFile → (serializedTree, bitstring).
  2. Rebuild the tree from the serialized string.
  3. Decode bits by walking the tree; if traversal ends mid‑path throw
       runtime_error("Encoding did not match Huffman tree.").
  4. Write the plaintext file and reclaim all heap memory.

Key components
- HuffmanCoder class with encoder() and decoder().
- Provided files: HuffmanTreeNode.*, ZapUtil.* (object only).
- main.cpp handles CLI parsing.  Makefile and unit tests supplied.

Standard errors
- runtime_error("Unable to open file <file>") for bad input/output files.
- Usage line above for malformed command line.

Testing note
  The exact bit pattern can differ from the reference binary, but the
  reported total bit count N must match.  Compare the stdout lines.
